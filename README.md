# nestore-social-assets

Public images for Nestore social posts (Threads and X). Threads fetches a post image from a public https URL, so the images live here while the drafts, plans and tokens stay in the private `nestore-social` repo.

Rules:

- Only images the owner approved for a post go here, at the moment that post is scheduled.
- One folder per week: `YYYY-Www/<post-id>.png`.
- A post links to its image as `https://raw.githubusercontent.com/Faktorealchik/nestore-social-assets/main/YYYY-Www/<post-id>.png`.
- Never move or rename a file a scheduled post links to.
- No screenshots of other people's content, no personal data, nothing internal.
